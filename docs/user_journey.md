# User Journey

## Marcelo Díaz Pérez

Marcelo prepara competiciones de Pokémon y utiliza parte de su tiempo de
entrenamiento para comprobar si las configuraciones que ha preparado pueden
responder adecuadamente ante determinadas situaciones de combate.

Para entender el recorrido de usuario se utilizan los siguientes conceptos:

- **Configuración de un Pokémon:** conjunto de características elegidas para un
  Pokémon antes del combate, como sus movimientos, habilidad, naturaleza y EVs.

  ### Situación de combate

- **Situación de combate:** estado concreto de una partida en el que intervienen
  unos Pokémon determinados, sus configuraciones y las condiciones presentes en
  ese momento, como el clima.

- **Acción:** decisión que puede tomar el jugador dentro de una situación de
  combate, por ejemplo utilizar uno de los movimientos disponibles.

- **Resultado de una acción:** efecto producido al realizar una acción dentro de
  una situación concreta. En el problema considerado interesa especialmente el
  daño producido al Pokémon rival y si este puede ser debilitado.

La frecuencia de uso dependerá de la proximidad de una competición y de las
situaciones que Marcelo encuentre durante sus partidas de entrenamiento.

Durante las semanas previas a un torneo podría utilizar la herramienta varias
veces para estudiar situaciones concretas que considere importantes.

El uso se produciría principalmente antes o después de las partidas de
entrenamiento. Marcelo puede encontrarse durante una partida con una situación
que no sabe resolver con seguridad y querer analizarla posteriormente con más
detalle.

El recorrido habitual sería el siguiente:

1. Marcelo identifica durante la preparación o el entrenamiento una situación
   de combate que considera relevante.

2. Recoge la información necesaria para describirla: los Pokémon implicados,
   sus configuraciones y las condiciones presentes en ese momento.

3. Identifica las acciones que podía realizar en esa situación, como los
   movimientos disponibles.

4. Comprueba qué resultado puede producir cada una de las acciones consideradas.

5. Valora si alguna de esas acciones permite alcanzar el resultado que buscaba,
   por ejemplo debilitar al Pokémon rival o dejarlo dentro de un determinado
   rango de vida.

6. Utiliza esa información para decidir si mantiene la configuración actual,
   modifica alguno de sus elementos o necesita seguir practicando esa situación.

7. Finaliza el análisis cuando dispone de información suficiente para continuar
   con su preparación.
