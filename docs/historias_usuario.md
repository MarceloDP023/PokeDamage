# Historias de usuario

Los datos de referencia necesarios para trabajar con los conceptos del dominio,
como Pokémon, estadísticas, tipos, movimientos, habilidades y naturalezas, se
obtendrán a partir de los ficheros CSV descargables de PokeAPI.

La procedencia y los datos necesarios para el proyecto se describen con más
detalle en [datos](../datos/datos.md).


## [HU001] Tiempo invertido en comprobar configuraciones antes de una competición

Antes de una competición dedico una parte importante del tiempo de preparación
a decidir qué configuraciones utilizar y a comprobar si realmente responden como
espero.

El problema es que no puedo saber con suficiente seguridad si una configuración
será adecuada únicamente a partir de cómo la he preparado. Para comprobarlo
necesito probarla durante el entrenamiento y observar cómo responde ante los
casos que considero relevantes para la competición.

Estas comprobaciones pueden requerir varias partidas y repetir el proceso con
distintas configuraciones hasta encontrar una que resulte adecuada. Cada cambio
en una configuración puede hacer necesario volver a realizar parte de las
pruebas anteriores.

Esto hace que una parte del tiempo de entrenamiento se dedique a validar
configuraciones en lugar de practicar directamente la toma de decisiones durante
los combates.

Además, si después de preparar y probar una configuración compruebo que no
responde como esperaba, parte del tiempo invertido en su preparación y prueba se
pierde y debo volver a modificarla y comprobarla de nuevo.


## [HU002] Dificultad para continuar el análisis desde distintos equipos

La preparación de una competición no siempre la realizo desde el mismo ordenador.

Esto dificulta continuar trabajando con las mismas situaciones y resultados
cuando cambio de equipo, especialmente si la información necesaria depende de una
instalación local concreta.

Necesito que el trabajo realizado durante la preparación no dependa del ordenador
concreto desde el que lo estoy realizando.
