# Datos

Para este proyecto haré uso de datos públicos de los que se obtendrá,
como Pokémon, sus movimientos, tipos, estadísticas, habilidades y naturalezas. 
El resto de datos mencionados ya dependen por parte del usuario ya que 
son variables externas a las características de los Pokémon.

La fuente de estos será PokeAPI, del que se pueden descargar sus datos, sin
tener que depender en tiempo real de su API.

Siendo estos datos suficientes para poder llegar a crear todas esas posibles
situaciones que nuestro usuario quiere simular rápidamente.
