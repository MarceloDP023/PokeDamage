# PokeDamage


## Cartas del juego de rol (Hecho en clase, pasado a limpio en casa)

## Descripción del Problema

El cliente Marcelo Díaz Pérez, jugador profesional de Pokémon, entrena de forma poco
óptima para sus torneos, haciendo que no consiga el rendimiento que el esperaría tener, lo
que puede hacer peligrar su carrera. Su gran problema es que consume mucho tiempo para probar
diferentes equipos y ver todas las posibles interacciones de daño que estos pueden tener en contra
de el resto de equipos que se suelen jugar (como de manera ofensiva y defensiva), ya que depende de 
factores como climas, repartición de EVs de sus pokémon y los rivales, movimientos, 
naturalezas, habilidades, ... Y poder comprobar rápidamnete estas variables 
de forma rápida, le haría usar su tiempo de forma mucho más óptima.
